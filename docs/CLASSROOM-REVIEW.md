The eight-step path is a review suggestion, not a fixed timetable or level assessment. Each step links to existing themes and grammar, offers a speaking task, and runs the normal due-first scheduler over that step's cards. Progress counts cards practiced, not proficiency or speaking-task completion. The resource week plan uses the same review goals.

## Grammar safeguards

- Time–manner–place is a useful starting pattern, not a rigid universal word order.
- The final consonant before infinitive -en determines regular -t/-d and -te/-de; stem spelling changes (leven → leef → geleefd) must not mislead the learner.
- No extra ge- applies to **unstressed prefixes**; not every matching initial letter sequence is a prefix.
- Movement uses hebben/ zijn according to activity versus directed movement; merely mentioning a location is insufficient.
- Both u voelt u and u voelt zich are valid.
- Singular diminutives take het; plural diminutives take de.
- Object reference with hij/hem is common for many de-nouns but is not universal.
- Of can coordinate alternatives or introduce an indirect question; these have different word orders. Dus can also occur with inversion.
